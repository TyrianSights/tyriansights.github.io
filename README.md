# Tyrian Sights

The official Tyrian Sights website: a responsive concept showcase using supplied brand and product artwork.

Site files are in `docs/`. To publish with GitHub Pages, open repository Settings → Pages, choose Deploy from a branch, then select the repository default branch and `/docs`.

Run locally with `python -m http.server 8000 --directory docs`.

Product images represent concepts; no checkout, availability claims, or finalized specifications are included.
